# EvoLumen Academy

Plataforma de cursos online de saúde emocional, de Erick Torritezi. Evolua com clareza.

Projeto pessoal, com um único administrador e professor. Pagamento único por curso (Mercado Pago), acesso vitalício ou por prazo, certificado automático, área de membros, painel administrativo e conformidade com a LGPD.

## Ambientes

| Ambiente | Branch | Uso |
| --- | --- | --- |
| Produção | `main` | Plataforma no ar |
| Staging | `staging` | Testes antes de produção |
